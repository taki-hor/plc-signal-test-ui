Write rules

The console does not send automatic pulses, clears, or retries. Follow the command’s confirmed procedure. Select Hold 1 or Manual 0 before you send 1. Hold records your choice after a fresh readback. It does not enforce the PLC value. An API cycle does not prove physical operation.

Timer details

The timer starts when you confirm 1. It stops at a fresh API completion signal. Send 0 uses a separate write. Timing includes network and polling delays. It does not measure mechanical travel time. Without a confirmed mapping, the console records no completion time.
